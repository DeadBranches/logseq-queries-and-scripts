# Introduction

This repository contains logseq advanced queries, kits modules, and some pages that implement the former.

Every `.md` file in this repository is a page in the user's logseq graph. Each list item represents a node in the graph.

# About Logseq Kits

Logseq kits is a framework that enables the user to execute arbitrary code from their graph.

Ingest the file `custom.js`, which contains the logseq kits framework.

# About Advanced Queries

Logseq advanced queries are written
in datascript. Datascript uses the datalog query language and a subset of clojurescript predicates.
